The **Solution set** of an equation is the set of all values of the variable (or variables) that make the equation true.
Two equations are **equivalent** if they have the same solution set
$x+3=7$ is equivalent to $x=4$
Adding / subtracting the same quantity to both sides of an equation yields an equivalent solution

$$
\begin{align}
3x-4&=2x+5 \\
3x-4+(-2x)&=2x+5+(-2x) \\
x-4&=5 \\
x-4+4&=5+4\\
x&=9
\end{align}
$$

Multiplying or dividing both sides of an equation by the same non-zero quantity yields an equivalent equation

$$
\begin{align}
\left( \frac{2}{3}\right)x&=4\\
\left(\frac32\right)\times\left(\frac23\right)x&=\left(\frac32\right)\times4 \\
x&=6
\end{align}
$$

If an equation is always true for any values of a variable, then the equation is called an **identity**. If the equation can never be true, then there is no solution.
