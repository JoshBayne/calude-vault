## What is a Network?
A computer network is a digital telecommunications network which allows nodes to share resources

Types of Nodes:
- Router
- Switch
- Firewall (software or hardware)
- Server
- Client (Laptops, PCs, Macs, Phones)

Server and Clients can be referred to as endpoints or end hosts

## Building a network
If two PCs are connected, this makes a simple network

## Clients
A Client is a devices that accesses a service made available by a server

## Servers
A server is a device that that provides functions or services for clients

## Switches
LAN - Local Area Network
Have many ports for end hosts to connect to
provide connectivity to hosts within same LAN
do not provide connectivity between lans/over the internet

## Routers
provide connectivity to the internet/WAN/between LANs
fewer network interfaces than switches

## Firewalls
### Hardware Network
